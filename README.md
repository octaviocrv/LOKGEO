Desenvolvi uma Landing Page moderna e responsiva para uma locadora de veículos em Contagem, MG. O projeto foi pensado para apresentar os serviços da empresa de forma clara e profissional, destacando a variedade de veículos disponíveis, incluindo carros, picapes e caminhonetes, além dos benefícios oferecidos, como locação sem burocracia e quilometragem livre. A página foi estruturada com foco em experiência do usuário, responsividade e conversão de potenciais clientes.

**[Alugue agora →](https://lokgeo.vercel.app)**

---

## A Proposta

Locação de veículos que não complica. Escolha, cotação via WhatsApp, retirada rápida e dirija com tranquilidade.

```
Contato → Cadastro simples → Retirada → Viagem 24h suportada
```

---

## Stack

- **Frontend** — React 19 + TypeScript + Tailwind CSS
- **Deploy** — Vercel
- **Infraestrutura** — Next.js / componentes otimizados

## Serviços

- 📅 **Locação Diária** — Flexibilidade para pessoa física
- 📆 **Locação Mensal** — Contato contínuo para PF e PJ
- 🏢 **Terceirização de Frotas** — Gestão completa para empresas

---

## Missão, Visão e Valores

**Missão:** Facilitar mobilidade cotidiana de pessoas e empresas com modernidade, acolhimento e transparência.

**Visão:** Ser a locadora número um da região metropolitana — flexível, sem burocracia.

**Valores:** Honestidade, valorização comunitária, segurança rigorosa e simplicidade.
